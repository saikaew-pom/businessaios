## 1. แก่นของผลิตภัณฑ์ (เริ่มที่นี่ ไม่ใช่ที่ฟีเจอร์)

คำถามแรกไม่ใช่ "จะจัดปุ่มยังไง" แต่คือ **"สิ่งนี้คืออะไรกันแน่"**

ตอนนี้ระบบ *ประพฤติตัว* เหมือนกล่องเครื่องมือของนักการตลาด — 11 เมนู, 12 เครื่องมือ, wizard 7 ขั้น, studio ที่มี dropdown โมเดล AI ให้เลือก 14 ตัว ผู้ใช้ต้องเป็นคนรู้เองว่าจะหยิบอะไร เมื่อไหร่ ตามลำดับไหน

แต่สิ่งที่มันควรเป็นคือ:

> **"เพื่อนคู่ร้านที่ทำการตลาดเป็น — ทุกเช้ามันรู้ว่าร้านคุณควรพูดอะไรกับลูกค้าวันนี้"**

ไม่ใช่กล่องเครื่องมือ แต่เป็น **เพื่อนร่วมงานรายวัน** — และการตัดสินใจออกแบบทุกข้อในเอกสารนี้ ไหลจากประโยคเดียวนี้

**เกณฑ์วัดที่ไม่ต่อรอง:** ป้าน้อย (60 ปี ใช้ LINE/FB/TikTok เป็น) และเด็ก ป.6 ต้องใช้สำเร็จโดยไม่มีใครสอน — สองคนนี้คือ regression test ถาวรของทุก release ไม่ใช่ persona ในสไลด์

## 2. คำมั่น 6 ข้อ (Design Commitments — บังคับใช้ ไม่ใช่แรงบันดาลใจ)

| # | คำมั่น | ความหมายเชิงปฏิบัติ |
|---|---|---|
| 1 | **ลดจนเหลือแต่แก่น** | ทุกหน้าจอมีงานเดียว ทุกหน้าจอมีปุ่ม primary เดียว สิ่งที่ผู้ใช้ 95% ไม่ใช้ → ซ่อนหลัง "ขั้นสูง" ไม่ใช่ลบทิ้ง แต่ต้องไม่เห็นก่อนเวลา |
| 2 | **UI ถอยให้เนื้อหาเด่น** | พระเอกของจอคือ *ของของผู้ใช้* — โพสต์ของเขา รูปของเขา ปฏิทินของเขา ไม่ใช่กลไกของเรา (ชื่อโมเดล, pillar, เครดิต, framework) กลไกอยู่หลังม่านเสมอ |
| 3 | **ภาษาเดียว: ภาษาคนขายของ** | ห้ามศัพท์การตลาด/อังกฤษบนจอ user-facing ทุกจุด (Hook→ประโยคเปิด, CTA→ชวนลูกค้าทำอะไรต่อ, Persona→ลูกค้าของเรา, Business DNA→ตัวตนธุรกิจ) — ศัพท์จริงอยู่ในโค้ดได้ บนจอไม่ได้ |
| 4 | **ซื่อสัตย์ทุกพิกเซล** | ราคา/ความสามารถบน landing ต้องตรงระบบจริง 100% (audit เดิมพบไม่ตรง — P0), ต้นทุนบอกก่อนกดเสมอ ("ใช้ 13 เครดิต ≈ 11 บาท" — คูณจากราคาจริงเฉลี่ย ~0.85 บาท/เครดิตของแพ็กเกจ Popular ใน `packages.ts`, ไม่ใช่เลขที่คิดขึ้นเอง — ดราฟต์แรกของแผนนี้เขียนผิดเป็น "ไม่ถึง 1 บาท" ซึ่งเป็นตัวอย่างของสิ่งที่ข้อนี้เองต้องจับให้ได้), ไม่มี badge NEW ปลอม, loading บอกความจริงว่ากำลังทำอะไร |
| 5 | **มือถือคือเครื่องหลัก** | ออกแบบที่ 375px ก่อน แล้วค่อยขยาย — ผู้ใช้ตัวจริงมีแต่มือถือ ปุ่มหลัก ≥ 44px ทุกจุด นิ้วโป้งเอื้อมถึง |
| 6 | **ความประณีตที่มองไม่เห็น** | empty state สอนงาน, error กู้คืนได้, undo แทน confirm dialog, focus state ครบ, ภาษาไทยตัดคำถูก, dark/light เท่าเทียมกัน — คุณภาพของส่วนที่คนไม่ทันสังเกต คือสิ่งที่ทำให้ "รู้สึกดีแต่บอกไม่ถูกว่าเพราะอะไร" |

## 3. สถาปัตยกรรมใหม่: จาก 11 เมนู เหลือ 4 ที่

ปัญหารากของระบบตอนนี้: **เมนูสะท้อนตารางในฐานข้อมูล ไม่ใช่ชีวิตผู้ใช้** (Works = content_items, Inbox = คิวรีวิว, Studio = media gen, Series = batch generator) ผู้ใช้ไม่ได้คิดเป็นตาราง เขาคิดเป็นงาน: *วันนี้ทำอะไร / สร้างโพสต์ / ดูตาราง / จัดการร้าน*

### 4 ที่ (destinations)

```
🏠 วันนี้          ✍️ สร้าง          📅 ปฏิทิน          🏪 ร้านของฉัน
   (บ้านใหม่)        (golden path)      (มีแล้ว ขัดเงา)     (ศูนย์รวมของร้าน)
```

| ที่ | คืออะไร | ดูดซับหน้าเดิม |
|---|---|---|
| **🏠 วันนี้** | หน้าแรกใหม่ของทั้ง OS — brief รายวัน: โพสต์ที่ถึงคิววันนี้ (กดก๊อป/แชร์ได้เลย), งานรอตรวจ, การ์ด "ทำต่อ" อันเดียวที่ระบบแนะนำ (ไม่ใช่ 4 CTA แข่งกันแบบ dashboard เดิม) | dashboard, inbox (งานรอตรวจกลายเป็น section หนึ่ง) |
| **✍️ สร้าง** | Golden Path จากแผน content (ขั้น 3): "วันนี้อยากโพสต์เรื่องอะไร" → 3 ปุ่มใหญ่ → การ์ดหัวข้อ → โพสต์เสร็จพร้อมรูป → ลงปฏิทิน | studio/series, tools ที่เกี่ยวกับ content (hook-library ฯลฯ กลายเป็นความสามารถในเส้นทาง ไม่ใช่หน้าแยก) |
| **📅 ปฏิทิน** | เดือนเดียวมองออกทั้งเดือน แยกร้าน/โปรเจกต์ ลากปรับได้ seasonal ปักไว้ — หน้าเดิมดีอยู่แล้ว ขัดเงา + ทำมือถือให้ดี | calendar, works (มุมมองตารางกลายเป็น "ดูแบบรายการ" ของปฏิทิน) |
| **🏪 ร้านของฉัน** | ทุกอย่างที่เป็น "ของร้าน" อยู่ที่เดียว: ข้อมูลร้าน+ลูกค้า 1 คน (brand profile), แผนร้าน (wizard 7 ขั้น — เปลี่ยนชื่อ step เป็นไทย), คลังรูป, เครดิต+เติมเงิน, โปรไฟล์+ตั้งค่า | studio/brand-kits, projects/[id], studio/library, billing, profile, settings/social |
| ⚙️ *ขั้นสูง* (ลิ้นชัก ไม่ใช่ที่ที่ 5) | สำหรับมือโปร/แอดมิน: Creative Studio เต็มรูป (เลือกโมเดล/aspect ratio), Works ตาราง, Series ตั้งค่าเอง, Developers, Admin | studio, works, developers, admin |

**กติกาการย้าย:** ทุก route เดิมต้องมีบ้านใหม่ (ตารางข้างบน map ครบ) — ไม่มีหน้ากำพร้า, redirect เดิม→ใหม่ทุกเส้น, ผู้ใช้เก่าไม่หลง

**เครื่องมือเดี่ยว 12 ตัว (`/tools/*`) — การตัดสินใจที่เจ็บแต่จำเป็น:** เลิกเป็น "ลิ้นชักเครื่องมือ" ที่ผู้ใช้ต้องรู้เองว่าหยิบอะไร → แต่ละตัวย้ายไปโผล่ *ในบริบทที่มันช่วยงานจริง* — เครื่องยนต์ข้างหลังอยู่ครบทุกตัว สิ่งที่ย้ายคือ "หน้าร้าน":

| เครื่องมือเดิม | บ้านใหม่ | กลายเป็นอะไร |
|---|---|---|
| persona-builder | 🏪 ข้อมูลร้าน → ลูกค้าของเรา | ตัว "สร้างลูกค้า 1 คน" ของ Brand Bootstrap (content ขั้น 1) |
| brand-voice | 🏪 ข้อมูลร้าน → เสียงของร้าน | ตัวช่วยร่าง/ปรับเสียงแบรนด์ในโปรไฟล์ |
| pain-generator | 🏪 ลูกค้าของเรา | ป้อน "คำบ่น 3 ประโยคคำต่อคำ" (Rule of One) |
| million-dollar-offer | 🏪 ข้อมูลร้าน → ข้อเสนอของร้าน | ออกแบบ offer → ไหลไปเติมบล็อกราคา/โปร/การันตีของโพสต์ขาย 15 ขั้น |
| hook-library | ✍️ หน้าแก้โพสต์ | ตัวเลือกตอนแตะแก้ "ประโยคเปิด" |
| objection-handler | ✍️ โพสต์ขาย 15 ขั้น | บล็อก "ตอบข้อโต้แย้ง 3 ข้อ" (แพงไป/ใช้ยาก/กลัวไม่ได้ผล) |
| value-proposition-canvas | 🏪 แผนร้าน → ขั้น "จุดขาย" | ซึมเข้าเป็นเนื้อเดียวกับ wizard ขั้น 4 |
| jtbd-generator | 🏪 แผนร้าน → ขั้น "ลูกค้าของเรา" | ซึมเข้า persona/เส้นทางลูกค้า |
| competitor-analysis | 🏪 แผนร้าน (ตัวช่วยขั้นจุดขาย) | ผู้ช่วยวิเคราะห์คู่แข่งตอนหาจุดต่าง |
| business-model-canvas | ⚙️ โหมดขั้นสูง | เครื่องมือกลยุทธ์ระดับลึก ใช้ไม่บ่อย |
| presentation-builder | ⚙️ โหมดขั้นสูง | คนละงานกับ social content — เก็บเป็นเครื่องมือโปร |
| tools/saved (บันทึก) | 🏪 คลังงานของร้าน | รวมกับคลังรูปเป็น "คลังของร้าน" ที่เดียว |

- ช่วงเปลี่ยนผ่าน: `/tools` เดิมเข้าได้ผ่านโหมดขั้นสูงจนกว่าบ้านใหม่จะเสร็จ + redirect ทุกเส้น ข้อมูลบันทึกเดิมอยู่ครบ
- **Candidate sunset:** jtbd-generator, business-model-canvas — ภาษานักกลยุทธ์ที่ผู้ใช้จริงแทบไม่แตะ ไม่ลบตอนนี้ แต่ถ้า usage data ยืนยันว่าไม่มีคนใช้ ให้กล้าตัด — เครื่องมือที่ไม่มีบริบทให้เกาะ = สัญญาณว่าควร sunset

## 4. ภาษาการออกแบบเดียว (Design Language)

ตอนนี้ระบบมีสีหลัก 1 สี + dark scale + emoji สุ่มเป็นไอคอน + spacing ตามใจ + `.input` ที่เพิ่งถูกนิยามกลางทาง — มันคือเสื้อผ้าที่ตัดทีละชิ้นไม่เคยลองทั้งชุด แผนนี้ตัดทั้งชุดเดียว:

### 4.1 Typography (สำคัญสุดสำหรับแอปไทย)
- คง **Noto Sans Thai** (อ่านง่าย ฐานดีอยู่แล้ว) แต่กำหนด **type scale เดียว 6 ขั้น**: Display 28 / Title 21 / Heading 17 / Body 15 / Caption 13 / Micro 11.5 — ห้ามหลุด scale
- **Line-height สำหรับสระบน-ล่างไทย**: body 1.65 ขึ้นไป (ไทยต้องการมากกว่า latin), ห้าม clip วรรณยุกต์
- ขนาด Body ต้องอ่านได้โดยคนอายุ 60 โดยไม่ซูม — นี่คือเหตุผลที่ Body = 15 ไม่ใช่ 13

### 4.2 สีและบทบาท
- ระบบสีที่มี (primary + dark scale + semantic success/warning/danger ที่เพิ่ง audit) **จัดเป็น token บทบาทชัด**: `surface / surface-raised / line / ink / ink-soft / accent / success / warning / danger` — component อ้าง token เท่านั้น ห้ามอ้างเลขสีตรง
- **accent ใช้ที่เดียวต่อจอ** — ปุ่ม primary เดียว สีจึงมีความหมาย (ตอนนี้ฟ้าทั้งหน้าจนไม่รู้อะไรสำคัญ)
- dark mode ที่ rollout เสร็จแล้ว = formalize เข้า token ไม่ทำใหม่

### 4.3 ไอคอน
- เลิก emoji-เป็นไอคอน (🎤💎🛡️🎣 ที่ audit ชี้ว่าดูไม่โปร) → **stroke icon set เดียว** (แนะนำ Lucide — น้ำหนักเดียว มุมมนเข้ากับ radius)
- emoji เก็บไว้เฉพาะ *ช่วงเวลามีอารมณ์* (ฉลอง 🎉, การ์ดหัวข้อ seasonal 🎊) — เป็นเครื่องปรุง ไม่ใช่โครงสร้าง

### 4.4 Component canon — 10 ชิ้นพอ
Card / Button (primary·secondary·ghost — อย่างละความหมาย) / ListItem / TapCard (เลือกได้) / Chip / Sheet (แทน modal บนมือถือ) / Field / EmptyState / Toast+Undo / CostLine ("ใช้ X เครดิต ≈ Y บาท")
— ทุกหน้าประกอบจาก 10 ชิ้นนี้ ใครอยากได้ชิ้นที่ 11 ต้องพิสูจน์ว่า 10 ชิ้นทำไม่ได้จริง

### 4.5 Motion
- ชุดเดียวทั้งระบบ: 200ms ease-out สำหรับเข้า, 150ms สำหรับออก, เคารพ `prefers-reduced-motion`
- Animation มีหน้าที่เดียว: บอกว่า *อะไรเพิ่งเกิดขึ้น* (ของใหม่ slide เข้า, ของถูกลบ fade ออก) — ไม่ใช่เครื่องประดับ

## 5. Brief รายหน้าจอ

### 🏠 วันนี้ (หน้าใหม่ — หัวใจของ redesign)
เปิดแอปตอนเช้าเห็น 3 อย่างตามลำดับ: (1) **โพสต์ของวันนี้** — ถ้ามีโพสต์ถึงคิว แสดงเต็มการ์ดพร้อมรูป ปุ่ม "ก๊อปไปโพสต์" / "แชร์" (2) **รอคุณตรวจ (n)** — งานที่ AI ทำเสร็จรอ approve (3) **การ์ดทำต่อ 1 ใบ** — ระบบแนะนำ next action เดียว ("ปฏิทินอาทิตย์หน้ายังว่าง — สร้างโพสต์ต่อไหม") ไม่มีสถิติโชว์เก๋ ๆ ไม่มี 4 CTA แข่งกัน — จบใน 1 จอมือถือ

### ✍️ สร้าง
คือ Golden Path ของแผน content (ขั้น 1-3 ของแผนนั้น) — เอกสารนี้ไม่ทำซ้ำ แต่กำหนดเพิ่ม: หน้านี้คือ *default* ของปุ่มกลาง bottom nav, ปุ่ม ✍️ ใหญ่กว่าปุ่มอื่น (แบบปุ่มชัตเตอร์กล้อง)

### 📅 ปฏิทิน
เดิมดีแล้ว ขัดเงา: มุมมองเดือนบนมือถือ (ตอนนี้เดสก์ท็อปเป็นหลัก), จุดสีตามสถานะ (ร่าง/พร้อม/โพสต์แล้ว — ใช้ semantic token), แตะวัน → sheet โผล่จากล่าง ไม่ใช่เปลี่ยนหน้า, "ดูแบบรายการ" = works เดิมในร่างใหม่

### 🏪 ร้านของฉัน
รวมของกระจัดกระจาย 6 หน้าเป็นบ้านเดียว จัดเป็น section: ข้อมูลร้าน (brand bootstrap จากแผน content ขั้น 1) / แผนร้าน (wizard เดิม ชื่อ step ไทย: ตัวตนธุรกิจ · ลูกค้าของเรา · เส้นทางลูกค้า · จุดขาย · ปฏิทินคอนเทนต์ · ขั้นตอนทำงาน · วัดผล) / คลังรูปของร้าน / เครดิตคงเหลือ+เติมเงิน (หน้า billing เดิมดีสุดในระบบ — เก็บ) / ตั้งค่า+ออกจากระบบ

เปลี่ยนจาก "ฟอร์ม 7 ช่อง" เป็น **"เห็นโพสต์เสร็จ → จิ้มส่วนที่อยากแก้"**: แสดงเป็นโพสต์จริงหน้าตาเหมือนบน Facebook ผู้ใช้แตะที่ประโยคเปิด/เนื้อหา/รูป เพื่อแก้เฉพาะจุด ✨ มีชิปบอกทิศ (จากแผน content ขั้น 6) — field label ตามคำมั่นข้อ 3 ทั้งหมด

### Creative Studio (เดิม)
กลายเป็น "โหมดขั้นสูง" ของ สร้าง — คนที่อยากเลือกโมเดล/aspect ratio/reference เองยังทำได้ครบ แต่ต้องเดินผ่านประตู "ขั้นสูง" เอง ผู้ใช้ทั่วไปไม่มีวันเจอคำว่า Base64 อีก

### Admin → Operations Console
ตาม audit เดิม §2.6 ทั้งหมด (search/filter/pagination, User Detail + เครื่องมือช่วยเหลือ, confirm ก่อนเปลี่ยน role) — แผนนี้เพิ่มข้อเดียว: admin ใช้ design language เดียวกับระบบหลัก ไม่ใช่ลูกเมียน้อย

### Landing
แก้ P0-2 เดิมทันทีที่แตะหน้านี้: ราคา/ความสามารถต้องตรงจริง — เรื่องความซื่อสัตย์ไม่รอ phase

## 6. ความประณีตที่มองไม่เห็น (บังคับทุกหน้าที่แตะ)

- **Empty state สอนงาน**: "ยังไม่มีโพสต์" → ภาพ + 1 ประโยค + ปุ่มเริ่ม ไม่ใช่กล่องเทาเปล่า
- **Loading บอกความจริง**: "กำลังร่างเสียงแบรนด์..." ไม่ใช่ spinner ใบ้
- **Undo แทน confirm**: ลบ/ย้าย → ทำทันที + toast "เลิกทำ" 5 วิ (ยกเว้น: จ่ายเงิน/ลบถาวร ยัง confirm)
- **CostLine ก่อนกดทุกปุ่มที่เสียเครดิต** — ไม่มีข้อยกเว้น
- **Error กู้คืนได้**: บอกว่าเกิดอะไร + ทำไงต่อ + ปุ่มลองใหม่ (เลิก `alert()` ทั้งระบบ)
- **แตะได้ ≥ 44px, focus ring ครบ, aria-label ครบ** (แก้ P2-7)
- **เลขเครดิตต้องตรงกันทุกจุด** (แก้ P2-3 — บั๊กจริง 100 vs 200)

## 7. สิ่งที่เราปฏิเสธ (The No List)

- ❌ เมนู 11 อันบน header — ตายแล้ว
- ❌ Dashboard ที่มี 4 CTA แข่งกัน
- ❌ "ลิ้นชักเครื่องมือ" ให้ผู้ใช้เดาเอง
- ❌ Emoji เป็นไอคอนระบบ / badge NEW ทุกใบ
- ❌ ศัพท์อังกฤษ-การตลาดบนจอผู้ใช้ (Business DNA, Persona, Pillar, Hook, CTA, BYOK...)
- ❌ Modal ซ้อน modal บนมือถือ / ฟอร์ม inline โผล่ใต้ fold

## 9. เกณฑ์วัดความสำเร็จ

| จำนวนแตะจาก "เปิดแอป" → "โพสต์วันนี้อยู่ในมือ" (ผู้ใช้เดิม) | ≤ 2 แตะ |
