# Content Playbook Upgrade Plan — ระบบ Gen Content คุณภาพ "Great"

> **Source of truth** สำหรับงานยกระดับระบบ content generation ทั้งเส้น
> อ้างอิง: `18-AI-Content-Writing-Playbook.md` (คอร์ส Claude Cowork for Business)
> สถานะล่าสุด: **วางแผนเสร็จ — ยังไม่เริ่มสร้าง** (อัปเดต: ส.ค. 2569)

## 1. เป้าหมาย

จากระบบที่ "gen โพสต์ได้" → เป็นระบบที่ **gen โพสต์แบบมีวิชา copywriting ในตัว** โดยผู้ใช้ไม่ต้องรู้สูตรเลย

โจทย์บังคับ 3 ข้อจากเจ้าของ product:

1. **"AI gen ให้ก่อน ผู้ใช้แค่ปรับ" ทุกจุด** — ผู้ใช้เราคิดเองกรอกเองจากศูนย์ไม่ได้
2. **Pipeline ต้องต่อกันครบเส้น**: Brand → AI สร้างธีมเสาหลัก → AI คิดหัวข้อตามประเภทโพสต์ → gen เนื้อหา → สร้างรูป → ลง calendar แยก project
3. **แตะทุก user journey** เพื่อประสบการณ์ great สุด — รวมถึงผู้ใช้แบบ "ป้าน้อย" (ดูข้อ 4)

## 2. หลักการออกแบบ (ทุกขั้นต้องยึด)

| หลักการ | รายละเอียด |
|---|---|
| **Slot architecture สำหรับ MiniMax** | MiniMax-M3 อ่อนงานแต่งอิสระ เก่ง extraction/classification/เติมช่องสั้น — ทุกฟีเจอร์ต้อง enumerate ตัวเลือก + แตกงานเป็น slot + ให้โค้ด deterministic ประกอบผลลัพธ์ (pattern เดียวกับ visual pipeline ที่พิสูจน์แล้ว) |
| **ผู้ใช้ "เลือก/ปรับ/อนุมัติ" ไม่ใช่ "แต่งเอง"** | ข้อยกเว้นเดียวที่ต้องพิมพ์เอง = ข้อเท็จจริง (ราคา/โปร/การันตี) ซึ่งเป็น guardrail ไม่ใช่ friction |
| **Guardrail ความจริง — บังคับด้วยโค้ด** | ราคา/รีวิว/รางวัล เติมด้วย interpolation จาก brand profile ตรง ๆ ไม่ใช่ให้โมเดล gen; field ว่าง = ข้ามบล็อกในโค้ด ไม่ใช่ขอร้องโมเดล (กัน พ.ร.บ.คุ้มครองผู้บริโภค + เป็นตัวแยกคุณภาพจาก generic AI) |
| **Taxonomy ซ่อนในเครื่องยนต์** | 14 ประเภท × 4 framework × pillars อยู่หลังบ้าน — ถ้าผู้ใช้ใหม่เห็น dropdown เลือก framework = ออกแบบพลาด |
| **Blind-tap-through ต้องยังได้ผลดี** | ผู้ใช้จะกด "โอเค" รัว ๆ โดยไม่อ่านหน้า confirm — default ทุกจุดต้องดีพอที่กดผ่านแล้วยังได้งานคุณภาพ |
| **ภาษาหน้าจอ = ภาษาคนขายของ** | ห้ามศัพท์การตลาด/อังกฤษบนหน้าจอผู้ใช้: Hook → "ประโยคเปิด", CTA → "ชวนลูกค้าทำอะไรต่อ", ห้ามคำว่า Pillar/Framework/Series โผล่ |
| **มือถือเป็นพลเมืองชั้นหนึ่ง** | ผู้ใช้เป้าหมายจำนวนมากมีแต่มือถือ — ทุกหน้าใหม่ต้องออกแบบจอแคบก่อน แล้วค่อยขยายขึ้นจอคอม |
| **บอกราคาเป็นภาษาคนก่อนกด** | "ครั้งนี้ใช้ 13 เครดิต (เหลือ 987)" — ฆ่าความกลัวเรื่องเงินก่อนผู้ใช้จะกลัว |

## 3. ผลตรวจระบบปัจจุบัน (ณ วันวางแผน)

ช่องว่าง 8 จุด เทียบ playbook + โจทย์บังคับ:

| # | ช่องว่าง | ระดับ |
|---|---|---|
| 1 | ไม่มีชั้น "คิดหัวข้อให้" (Topic Picker) — `topic` เป็น required free-text ผู้ใช้ต้องคิดเอง | 🔴 วิกฤต |
| 2 | ไม่มี Brand Bootstrap — brand profile กรอกมือทุกช่อง และข้อมูล wizard (brand_card/personas/pain_points/positioning ใน `projects.step_data`) ไม่เคยไหลมาใช้ | 🔴 วิกฤต |
| 3 | Pillar 2 ความหมายปนกัน — funnel stage (awareness→conversion ที่ hard-code ใน `DEFAULT_SLOTS`) vs ธีมประจำแบรนด์ (business-specific) ต้องมีทั้ง 2 แกน | 🟠 สูง |
| 4 | Taxonomy 14 ประเภท (4 กลุ่มเป้าหมาย: ขายฝัน/Expert/Engagement/Review) ไม่ถูกใช้ → calendar แบน 4 รสซ้ำ | 🟠 สูง |
| 5 | ไม่มี Seasonal (สงกรานต์/เปิดเทอม/วันแม่/9.9/ฤดูฝน) | 🟡 กลาง |
| 6 | ไม่มีการรีดสื่อ (playbook Step 6: 1 โพสต์ → อัลบั้ม/Reels/LINE) | 🟡 กลาง |
| 7 | ไม่มีช่อง voice samples (ตัวอย่างโพสต์ที่เคยเวิร์ก) — lever คุณภาพที่ถูกที่สุดสำหรับโมเดลอ่อน | 🟡 กลาง |
| 8 | Brand context ถูกส่งเป็น `JSON.stringify` ดิบ — ควรเป็นบล็อกไทยติดป้ายตามโครง 3 ชั้น (บทบาท/บริบท/ตัวอย่าง) | ⚪ เล็ก |

บั๊กที่เจอระหว่างตรวจ: `regenerate-field` (ปุ่ม ✨) ไม่ส่ง brand context เข้า prompt เลย — AI เขียนใหม่โดยไม่รู้จักแบรนด์

## 4. บททดสอบ "ป้าน้อย" (persona stress test)

ป้าอายุ 60 ใช้ LINE/FB/TikTok เป็น ขายแกงถุง เปิดแอปครั้งแรก: ตายตั้งแต่แถบเมนู (Works? Inbox? Developers?) ก่อนถึงเครื่องยนต์ — หลงเข้า Creative Studio เจอ "Base64" ปิดแอป, เจอกล่อง topic ว่างไม่รู้พิมพ์อะไร, เจอช่อง Hook/CTA อ่านไม่ออก, ไม่กล้ากดเพราะกลัวเสียเงิน → **feedback จริงคือความเงียบ: "ให้หลานทำให้ดีกว่า"**

บทเรียน: แผนซ่อมเครื่องยนต์อย่างเดียวไม่พอ ต้องซ่อมประตูหน้าบ้านด้วย (→ ขั้นที่ 3 Golden Path) และป้าน้อยไม่ใช่ edge case — ระบบที่ป้าใช้ได้ คนอายุ 35 จะรู้สึกง่ายไปด้วยอัตโนมัติ

## 5. User Journey เป้าหมาย (A→I)

| ขั้น | AI ทำให้ก่อน | ผู้ใช้ทำ | สถานะตอนนี้ |
|---|---|---|---|
| A. เริ่ม | — | พิมพ์ชื่อร้าน + ขายอะไรให้ใคร 1 บรรทัด (หรือเลือกแผน wizard ที่มี) | wizard มีแต่ไม่ไหลต่อ ❌ |
| B. Brand draft | ร่างโปรไฟล์ทั้งหมด + ลูกค้า 1 คน + คำบ่น 3 ประโยค | ปรับ/ยืนยันเป็นการ์ด, แปะโพสต์เก่า (optional) | กรอกมือหมด ❌ |
| C. ธีมเสาหลัก | เสนอธีม 3-5 อัน พร้อมเหตุผล | ติ๊กเลือก/เปลี่ยนชื่อ | hard-code 4 funnel ❌ |
| D. เลือกหัวข้อ | การ์ดหัวข้อ 8-12 ใบ/ธีม ติด tag ประเภท + seasonal | **แตะเลือก** (ไม่พิมพ์) | ต้องพิมพ์เอง ❌ ← จุดพังใหญ่สุด |
| E. Gen เนื้อหา | Framework engine ≤7 โพสต์/batch | รีวิวใน editor, ✨ บอกทิศ | มี series แต่ไร้โครง ⚠️ |
| F. โพสต์ขาย | ฟอร์ม 15 ขั้น pre-fill จากโปรไฟล์ | เติมตัวเลขจริง (ราคา/โปร/การันตี) | ยังไม่มี ❌ |
| G. รูปภาพ | visual slot pipeline เดิม | อนุมัติรูป | เวิร์ก ✅ |
| H. ตรวจก่อนโพสต์ | AI ตรวจข้อที่เช็คได้ + แสดง checklist | เช็คข้อที่คนต้องเช็คเอง | ยังไม่มี ❌ |
| I. Calendar | จัดตารางอัตโนมัติ, seasonal ปักใกล้วันจริง | ลากปรับ | เวิร์ก (แยก project แล้ว) ✅ |

## 6. Roadmap 7 ขั้น

> ทำทีละขั้น รอยืนยันก่อนไปขั้นถัดไป (ตามธรรมเนียม repo) — ทุกขั้นมี migration gate test ถ้าแตะ schema, ผ่าน code-reviewer ก่อนถือว่าเสร็จ

### ☐ ขั้นที่ 1 — Brand Bootstrap + ลูกค้า 1 คน (กลาง)

- ทางเข้า 2 ทาง: (ก) มีแผน wizard → ปุ่มเดียว "สร้าง Brand Profile จากแผนของคุณ" — map แบบ deterministic: step1 brand_card → summary/tone, step2 personas → persona seed, step3 pain_points → คำบ่น 3 ประโยค seed, step4 positioning → offers (แทบไม่ใช้ AI) (ข) ไม่มีแผน → ตอบ 3 คำถามสั้นภาษาคน → AI call เดียวร่างทุก field
- เพิ่ม `persona` (ชื่อ/อายุ/อาชีพ/ชีวิตประจำวัน 1 ย่อหน้า/**คำบ่น 3 ประโยคคำต่อคำ** — ห้ามยาวกว่านี้) + `voice_samples` ใน brand profile (migration + gate test)
- แก้ ✨ regenerate-field ให้ได้ brand snapshot + persona
- เปลี่ยน brand context จาก JSON ดิบ → บล็อกไทยติดป้ายตามโครง 3 ชั้นของ playbook

### ☐ ขั้นที่ 2 — ธีมเสาหลัก + Topic Picker (กลาง — impact ต่อผู้ใช้สูงสุด) 🔥

- AI เสนอธีมเสาหลัก 3-5 อันจากแบรนด์ (แกนธีม แยกจากแกน funnel)
- การ์ดหัวข้อ 8-12 ใบ/ธีม แต่ละใบติด tag: ประเภท (enum 14 แบบ), กลุ่มเป้าหมาย (ขายฝัน/Expert/Engagement/Review), framework แนะนำ, seasonal flag
- ตารางปฏิทินการตลาดไทย static (สงกรานต์/เปิดเทอม/วันแม่/ตรุษจีน/9.9/11.11/ฤดูฝน...) ฉีดเข้า ideation — ไม่ใช้ AI, ฟรี
- แตะเลือก → ป้อนเข้า series generator เดิม (pre-fill topic) — **ไม่ต้องรื้อ engine ก็ ship ได้**
- "พิมพ์หัวข้อเอง" กลายเป็น fallback ไม่ใช่ default
- De-dup ที่ชั้น topic (history ต่อ pillar) เพิ่มจากชั้น hook เดิม — หัวข้อจากเครื่อง cluster ซ้ำเก่งกว่าหัวข้อจากคน
- Ideation ต้องถูก: output แค่ชื่อเรื่อง + enum tags (ห้าม draft caption ตอน ideation), cache ผลไว้, ราคาถูก/ฟรีให้เห็นชัด

### ☐ ขั้นที่ 3 — Golden Path "เส้นทางป้าน้อย" + ปฏิรูปภาษา (กลาง)

- หน้าแรก content studio = คำถามเดียว **"วันนี้อยากโพสต์เรื่องอะไร"** + ปุ่มใหญ่ 3 ปุ่ม: `ขายของ` / `เล่าเรื่องร้าน` / `ให้ความรู้ลูกค้า` → การ์ดหัวข้อ (จากขั้น 2) → เห็น**โพสต์เสร็จพร้อมรูป** → ปุ่มเดียว "ลงปฏิทิน / ก๊อปไปโพสต์"
- เกณฑ์วัด: **โพสต์แรกเสร็จใน 3 นาที พิมพ์ไม่เกิน 2 ช่อง**
- ปฏิรูปภาษาทั้งระบบ: Hook → "ประโยคเปิด", Caption → "เนื้อหาโพสต์", CTA → "ชวนลูกค้าทำอะไรต่อ", Visual suggestion → "ภาพประกอบ" ฯลฯ
- เมนูขั้นสูง (Works/Inbox/Series/Developers) ซ่อนหลัง "ขั้นสูง" สำหรับ first-time user — มือโปรเปิดได้
- แสดงต้นทุนก่อนกดทุกปุ่มที่เสียเครดิต
- Default platforms → FB + LINE + TikTok (จาก FB + IG)
- ทุกหน้าใหม่: mobile-first

### ☐ ขั้นที่ 4 — Framework Engine (ใหญ่)

- `frameworks.ts`: slot template ของ How-to / เรื่องเล่า 5 จังหวะ (เริ่ม→อุปสรรค→ดิ้นรน→จุดเปลี่ยน→ผลลัพธ์) / Mindset + variants (Tips, Do-Don't, Stat/Fact)
- ระบบพาดหัว 2-จาก-5 (ผลลัพธ์/คำถาม/ปัญหา/เวลา/เงื่อนไขไม่น่าเป็นไปได้) — โมเดลเลือกคู่, **โค้ด validate**
- Pillar → framework เป็น **weighted default หมุนใน โค้ด** (ไม่ใช่กฎตายตัว ไม่ใช่ให้โมเดลเลือก): education → {How-to, Tips, Do-Don't, Stat/Fact} ฯลฯ
- **เพิ่ม Engagement เข้าสูตรหมุน** (Q&A/Seasonal/ชวนคุย) — สัดส่วนเดือนปกติ ~ ความรู้ 40 / awareness 25 / engagement 15 / social proof 10 / ขาย 10
- คำบ่น 3 ประโยคของ persona → ฉีดเข้า hook slots ตรง ๆ
- Prompt บังคับ: ทุกโพสต์ต้องมีรายละเอียดจริงจากโปรไฟล์ ≥1 จุด (adjective-stacking = fail)
- ความยาว caption ตาม framework ไม่ใช่กฎ "3-5 บรรทัด" ตายตัว
- ⚠️ วัด token per-post จริงก่อน commit ว่า batch 7 ยังไหว (โครง slot อาจ "ลด" token เทียบ free prose — ต้องวัด)
- ภาษาไทยตอนประกอบ: นะคะ/ครับ เป็น setting ระดับแบรนด์ฉีดทุก slot, slot หยาบระดับประโยค/ย่อหน้า (ให้โมเดลเขียนประโยคเต็มธรรมชาติ โค้ดจัดลำดับ), golden set 10 แบรนด์ไว้ regression test ทุกครั้งที่แก้ prompt

### ☐ ขั้นที่ 5 — โพสต์ขาย 15 ขั้น + ปุ่มป้ายยาย่อ (กลาง)

- flow แยก "สร้างโพสต์ขาย": ฟอร์ม pre-fill จาก offers/persona/คำบ่น — ผู้ใช้เติมเฉพาะข้อเท็จจริง (ราคา/โปร/การันตี/ช่องทาง)
- บล็อกไหนไม่มีข้อมูลจริง → ข้ามในโค้ด (ตาม playbook: "ถ้ายังไม่มี ให้ข้ามข้อนั้นไป ดีกว่าแต่งขึ้น")
- ข้อ 3 (เคยลองแล้วไม่เวิร์ก) — เล่าเป็น "ประเภทวิธี" ห้ามเอ่ยยี่ห้อคู่แข่ง (บังคับใน prompt)
- ปุ่ม "ปิดจบแบบขายเนียน ๆ" (ป้ายยาย่อ) แปะท้ายโพสต์ How-to/เรื่องเล่า/Mindset ได้ทุกโพสต์ — ตอบพฤติกรรม SME ไทยที่กลัวขายแข็ง
- Framing: "โพสต์เปิดตัวโปร" (ตามโอกาส) ไม่ใช่ "โพสต์ขายของ" (ตามตัวตน)

### ☐ ขั้นที่ 6 — ✨ บอกทิศ + Checklist ก่อนโพสต์ (เล็ก)

- ชิปโทน 4-6 อัน + อารมณ์ 5 แบบ (กลัวพลาด/คุ้ม/ไม่ตกขบวน/สะดวก/คนพิเศษ) เป็น enumerated modifier บนปุ่ม ✨ — ตัด 8 มิติเต็มทิ้ง (choice paralysis)
- Checklist 6 ข้อแสดงใน editor (ฟรี ไม่ใช้ AI) + ปุ่ม "ตรวจ 60 วิ" (AI เช็คเฉพาะข้อที่เช็คได้: พาดหัว 1 ไอเดีย / CTA เดียว / คำเคลม trace ถึงข้อมูลโปรไฟล์ / ตรงเสียงแบรนด์) — ข้อที่คนต้องเช็คเอง (อ่านออกเสียง/โปรจริงไหม) แสดงเป็นรายการเตือน

### ☐ ขั้นที่ 7 — รีดสื่อ (Repurpose) (กลาง — เลื่อนได้)

- ปุ่ม "รีดต่อ" บนโพสต์ที่อนุมัติแล้ว → อัลบั้มภาพ / สคริปต์ Reels-TikTok / ข้อความ LINE broadcast → เข้าคิวรีวิวเดิม
- Token ถูก (แปลงของเดิม ไม่ใช่แต่งใหม่) — ROI สูงสุดเมื่อผู้ใช้มีโพสต์ดีอยู่แล้ว

### ตัดทิ้ง / ไม่ทำ

- สไตล์ 8 มิติเต็มของ playbook Step 3 (เหลือชิป 4-6 อัน)
- แปลงมุมมองตัวละคร (playbook Step 5) — novelty, demand ต่ำ
- วางแผนถ่าย/ตัดวิดีโอ (playbook Step 7) — นอก scope

## 7. ความเสี่ยงหลักที่ต้องคุม

1. **Choice paralysis ปลอมตัวเป็นความยืดหยุ่น** — taxonomy อยู่หลังบ้านเท่านั้น, progressive disclosure
2. **Edit-rate collapse** — "AI gen ก่อน" กลายเป็น "ผู้ใช้อนุมัติโดยไม่อ่าน": วัด edit-rate ต่อ surface, บังคับ confirm เฉพาะข้อเท็จจริง (ราคา/คำเคลม)
3. **Token ทบต้น** — pipeline มี ~4 AI pass (profile→pillars→topics→posts→visual): ideation ต้อง output สั้น + cache, กด "ขอเพิ่ม" ซ้ำ ๆ ต้องไม่แพงกว่า series call
4. **ความซ้ำระดับ scale** — de-dup ชั้น topic เพิ่มจากชั้น hook
5. **คุณภาพไทยตอนประกอบ slot** — register/particle consistency + golden set eval
6. **พฤติกรรม SME จริง** — กลัวขายแข็ง (→ ป้ายยาย่อ default), โพสต์เป็น burst แล้วหาย (→ calendar 30 วันคือไม้ค้ำความสม่ำเสมอ)
7. **Trust cliff** — fact ในโพสต์ขายพลาดครั้งเดียว = เสียลูกค้า + ความเสี่ยงกฎหมาย → fact เติมด้วยโค้ดเท่านั้น

## 8. บันทึกการรีวิว

- **รีวิวรอบ 1** (ผู้เชี่ยวชาญการตลาด): พบ gap 8 จุด, ยืนยัน slot architecture + truthfulness guardrail ถูกทาง, ชี้ Topic Picker เป็น "การเปลี่ยนคำถามสอบให้เป็นเมนูอาหาร" — คำแนะนำสำคัญสุด: ทำ Topic Picker ให้ "พิมพ์เอง" เป็น fallback
- **รีวิวรอบ 2** (persona test "ป้าน้อย" อายุ 60): เครื่องยนต์ดีแต่ประตูหน้าบ้านพัง → เพิ่มขั้นที่ 3 Golden Path + ปฏิรูปภาษา + mobile-first + แสดงต้นทุนก่อนกด
